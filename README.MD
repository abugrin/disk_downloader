# Загрузчик Яндекс Диска

Выгрузка личных и Общих Дисков Яндекс 360 для бизнеса через сервисное приложение.
Поддерживает один источник или список из CSV, терминальное меню и запуск из командной строки.

> Неофициальный инструмент. Является примером использования API.

## Требования

- Windows, macOS или Linux.
- [uv](https://docs.astral.sh/uv/getting-started/installation/) версии 0.9.28 или новее.
- Python 3.13 — uv установит его при необходимости.
- Сервисное приложение организации и свободное место для скачиваемых файлов.
- Для Общих Дисков — email сотрудника с доступом на чтение к выбранным дискам.

## Установка uv

macOS / Linux:

```shell
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Windows PowerShell:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Откройте новый терминал и проверьте установку командой `uv --version`.

## Запуск из GitHub

Откройте терминал в папке, куда нужно сохранить файлы, и выполните:

```shell
uv run --script https://raw.githubusercontent.com/abugrin/disk_downloader/main/downloader.py
```

Клонировать репозиторий не нужно. uv загрузит скрипт, установит Python и зависимости
и откроет меню. Настройки `.env`, CSV и папки выгрузки используются в текущей папке
терминала. Для новой версии повторите эту же команду.

Параметры командной строки можно добавить после URL, например:

```shell
uv run --script https://raw.githubusercontent.com/abugrin/disk_downloader/main/downloader.py --email reader@example.com --vdhash ExampleDiskHash1
```

## Установка из репозитория

```shell
git clone https://github.com/abugrin/disk_downloader.git
cd disk_downloader
uv sync --locked
uv run --locked python downloader.py
```

Можно также скачать ZIP-архив репозитория. Окружение `.venv` создаётся автоматически;
активировать его не нужно. Команды ниже выполняются из папки проекта.

## Настройка и меню

Создайте [сервисное приложение](https://yandex.ru/support/yandex-360/business/admin/ru/security-service-applications)
с правами:

```text
cloud_api:disk.info
cloud_api:disk.read
cloud_api:disk.app_folder
```

Запуск без параметров открывает меню:

- Личный Диск — один пользователь.
- Личные Диски — список email из CSV.
- Общий Диск — один VDHASH.
- Общие Диски — список VDHASH из CSV.
- Настроить CLIENT_ID и CLIENT_SECRET.
- Выход.

Выбор — стрелками и Enter. В настройках укажите реквизиты сервисного приложения.
`CLIENT_SECRET` скрыт при вводе; пустой ввод сохраняет уже настроенный секрет.
Настройки записываются в `.env` текущей папки и сразу применяются. Если настроек ещё
нет, меню запросит их перед первой выгрузкой. После выгрузки можно выбрать следующий пункт.

Настройки можно открыть отдельно:

```shell
uv run --locked python downloader.py --configure
```

Вместо меню можно создать `.env` по образцу `.env.example` с переменными
`CLIENT_ID` и `CLIENT_SECRET` или задать их в окружении процесса.
При загрузке настроек переменные окружения имеют приоритет над `.env`.

## Личные Диски

Один пользователь:

```shell
uv run --locked python downloader.py --email user@example.com
```

Список пользователей в `users.csv` — по образцу [users.example.csv](users.example.csv):

```csv
email
user1@example.com
user2@example.com
```

```shell
uv run --locked python downloader.py --csv users.csv
```

Файлы сохраняются в отдельную папку с email пользователя, например `user@example.com/`.

## Общие Диски

Откройте Общий Диск в браузере и скопируйте его метку из фрагмента URL
`/vd/<VDHASH>/`. Указывайте только метку, без URL, сохраняя регистр символов.
`--email` задаёт сотрудника, которому разрешено чтение этого диска: токен
получается от его имени. VDHASH не заменяет email и сам по себе не предоставляет доступ.

Один диск:

```shell
uv run --locked python downloader.py --email reader@example.com --vdhash ExampleDiskHash1
```

Список в `shared-disks.csv` — по образцу [shared-disks.example.csv](shared-disks.example.csv):

```csv
VDHASH
ExampleDiskHash1
ExampleDiskHash2
```

```shell
uv run --locked python downloader.py --email reader@example.com --vdhash-csv shared-disks.csv
```

Для всего списка используется один email сотрудника с доступом к этим дискам.
Каждый диск сохраняется в `shared/<VDHASH>/` с исходной структурой папок.
Если локальные имена совпадают без учёта регистра, к имени добавляется суффикс.

Оба вида CSV поддерживают UTF-8, в том числе с BOM, и разделители `,` или `;`.
Можно использовать нужную колонку в таблице с другими колонками либо список
без заголовка, по одному значению в строке. Пустые строки и повторы пропускаются.
Для email регистр не учитывается; для VDHASH — учитывается. Весь CSV проверяется
до начала выгрузки.


Токен обновляется автоматически за 5 минут до истечения часового срока,
в том числе во время долгого скачивания. Срок берётся из `expires_in` ответа
сервера (по умолчанию — 1 час); для коротких сроков запас составляет 10%.
Обновление общее для параллельных скачиваний и отображается в журнале.
Просроченный токен в новые запросы не передаётся.

Статус выводится каждые 10 секунд: текущий этап и папка, найденные файлы,
завершённые скачивания, ошибки и очередь. «Без новых результатов» означает время
с последнего обновления счётчиков; запрос к API или скачивание большого файла
могут продолжаться в это время. Интервал можно изменить:

```shell
uv run --locked python downloader.py --email reader@example.com --vdhash-csv shared-disks.csv --status-interval 5
```

В конце выводится итог. Код завершения: `0` — без ошибок,
`1` — есть ошибки выгрузки, `2` — ошибка входных данных, `130` — отмена через Ctrl+C.
Меню при выходе возвращает `1`, если хотя бы одна выгрузка в этой сессии завершилась с ошибками.
Для запуска без интерактивного терминала используйте параметры командной строки.

Справка:

```shell
uv run --locked python downloader.py --help
```
