# Загрузчик Яндекс Диска

Выгрузка файлов пользователей Яндекс 360 для бизнеса через сервисное приложение.
Можно скачать Диск одного пользователя или обработать список из CSV.

> Неофициальный инструмент. Является примером использования API.

## Требования

- Windows, macOS или Linux.
- [uv](https://docs.astral.sh/uv/getting-started/installation/) версии 0.9.28 или новее.
- Python 3.13 — uv установит его при необходимости.
- Сервисное приложение с доступом к пользователям организации.
- Свободное место для скачиваемых файлов.

## Установка

Установите uv.

macOS / Linux:

```shell
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Windows PowerShell:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Откройте новый терминал и проверьте установку командой `uv --version`.
Затем скачайте проект и установите зависимости:

```shell
git clone https://github.com/abugrin/disk_downloader.git
cd disk_downloader
uv sync --locked
```

Вместо клонирования можно скачать ZIP-архив репозитория и открыть терминал
в распакованной папке. Окружение `.venv` создаётся автоматически; активировать его не нужно.

## Настройка

1. Создайте [сервисное приложение](https://yandex.ru/support/yandex-360/business/admin/ru/security-service-applications)
   с правами:

   ```text
   cloud_api:disk.info
   cloud_api:disk.read
   cloud_api:disk.app_folder
   ```

2. Скопируйте `.env.example` в `.env`.

   macOS / Linux:

   ```shell
   cp .env.example .env
   ```

   Windows PowerShell:

   ```powershell
   Copy-Item .env.example .env
   ```

3. Заполните в `.env` значения `CLIENT_ID` и `CLIENT_SECRET` своего приложения.
   Если `.env` уже настроен, используйте его. Можно также задать эти переменные
   в окружении процесса — они имеют приоритет над `.env`.

## Выгрузка одного пользователя

Выполняйте команды из папки проекта:

```shell
uv run --locked python downloader.py
```

Введите email пользователя. Файлы сохраняются в отдельную папку с его email,
например `user@example.com/`. Одновременно скачивается не более десяти файлов.

Папки с точным именем **«Файлы Мессенджера»** и их содержимое пропускаются.
Локальные имена преобразуются для совместимости с Windows; файлы на Диске не меняются.
Повторный запуск скачивает файлы заново и может перезаписать локальные копии.
Возобновления прерванного скачивания нет.

## Выгрузка по CSV

Создайте `users.csv` по образцу [users.example.csv](users.example.csv):

```csv
email
user1@example.com
user2@example.com
```

```shell
uv run --locked python downloader.py --csv users.csv
```

Поддерживается UTF-8, в том числе с BOM, и разделители `,` или `;`.
Можно использовать колонку `email` в таблице с другими колонками либо список
без заголовка, по одному email в строке. Пустые строки и повторные адреса пропускаются.

Пользователи обрабатываются по очереди, каждый в свою папку. Ошибка одного
пользователя или файла не останавливает остальные выгрузки. Ошибки формата CSV
выводятся до начала скачивания.

## Статус и завершение

Статус выводится каждые 10 секунд: текущий этап и папка, найденные файлы,
завершённые скачивания, ошибки и очередь. «Без новых результатов» означает время
с последнего обновления счётчиков; запрос к API или скачивание большого файла
могут продолжаться в это время.

Интервал можно изменить для одиночной выгрузки или CSV:

```shell
uv run --locked python downloader.py --csv users.csv --status-interval 5
```

В конце выводится итог. Код завершения: `0` — выгрузка завершена без ошибок,
`1` — есть ошибки выгрузки, `2` — ошибка входных данных, `130` — отмена через Ctrl+C.

Справка по параметрам:

```shell
uv run --locked python downloader.py --help
```
