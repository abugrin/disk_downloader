# Загрузчик Яндекс Диска

Выгрузка личных и Общих Дисков Яндекс 360 для бизнеса через сервисное приложение.
Поддерживает один источник или список из CSV, терминальное меню и запуск из командной строки.

> Неофициальный инструмент. Является примером использования API.

## Требования

- Windows, macOS или Linux.
- [uv](https://docs.astral.sh/uv/getting-started/installation/) версии 0.9.28 или новее.
- Python 3.13 — uv установит его при необходимости.
- Сервисное приложение организации и свободное место для скачиваемых файлов.
- Для Общих Дисков — email сотрудника с доступом на чтение к выбранным дискам.

## Установка uv

macOS / Linux:

```shell
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Windows PowerShell:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Откройте новый терминал и проверьте установку командой `uv --version`.

## Запуск из GitHub

Откройте терминал в папке, куда нужно сохранить файлы, и выполните:

```shell
uv run --script https://raw.githubusercontent.com/abugrin/disk_downloader/main/downloader.py
```

Клонировать репозиторий не нужно. uv загрузит скрипт, установит Python и зависимости
и откроет меню. Настройки `.env` и относительные пути CSV используются в текущей
папке терминала. Файлы по умолчанию сохраняются туда же; папку загрузки можно
изменить в меню. Для новой версии повторите эту же команду.

Параметры командной строки можно добавить после URL, например:

```shell
uv run --script https://raw.githubusercontent.com/abugrin/disk_downloader/main/downloader.py --email reader@example.com --vdhash ExampleDiskHash1
```

## Установка из репозитория

```shell
git clone https://github.com/abugrin/disk_downloader.git
cd disk_downloader
uv sync --locked
uv run --locked python downloader.py
```

Можно также скачать ZIP-архив репозитория. Окружение `.venv` создаётся автоматически;
активировать его не нужно. Команды ниже выполняются из папки проекта.

## Настройка и меню

Создайте [сервисное приложение](https://yandex.ru/support/yandex-360/business/admin/ru/security-service-applications)
с правами:

```text
cloud_api:disk.info
cloud_api:disk.read
cloud_api:disk.app_folder
```

Запуск без параметров открывает меню:

- Личный Диск — один пользователь.
- Личные Диски — список email из CSV.
- Общий Диск — один VDHASH.
- Общие Диски — список VDHASH из CSV.
- Настроить CLIENT_ID и CLIENT_SECRET.
- Настроить количество повторов (retry).
- Настроить папку загрузки.
- Настроить дату начала выгрузки.
- Выход.

Выбор — стрелками и Enter. В настройках укажите реквизиты сервисного приложения.
`CLIENT_SECRET` скрыт при вводе; пустой ввод сохраняет уже настроенный секрет.
Настройки записываются в `.env` текущей папки и сразу применяются. Если настроек ещё
нет, меню запросит их перед первой выгрузкой. После выгрузки можно выбрать следующий пункт.

В пункте «Настроить количество повторов (retry)» выберите от **0 до 3 повторов
после первой попытки**. По умолчанию — 0: одна попытка без повторов и пауз.
Максимум — 3 повтора. Значение сохраняется
как `MAX_RETRIES` в `.env` и применяется к скачиванию, запросам API и получению
токена, в том числе при запуске из командной строки. Паузы — 2, 4 и 8 секунд по числу повторов, со случайной
добавкой до 25%; более длинный
`Retry-After` от сервера имеет приоритет.

В пункте «Настроить папку загрузки» выберите «Указать путь». Поддерживаются
относительные пути `backups`, `../backups` (на Windows также `.\backups`),
абсолютные пути Linux/macOS `/mnt/backup`, а при запуске на Windows —
`D:\Backups`, `D:/Backups` и сетевые пути `\\server\share\Backups`.
Путь вида `D:backups` не поддерживается: укажите полный путь с буквой диска.

Путь сохраняется как `DOWNLOAD_DIR` в `.env` и применяется во всех режимах.
Относительные пути отсчитываются от папки запуска. Пункт «Папка запуска
(по умолчанию)» сбрасывает настройку; пустой или отсутствующий `DOWNLOAD_DIR`
также сохраняет прежнее поведение. `.env`, `logs` и относительные пути CSV
остаются в папке запуска. Уже скачанные файлы при смене настройки не переносятся.

В пункте «Настроить дату начала выгрузки» укажите дату в формате `yyyy-mm-dd`,
например `2026-10-01`. Будут скачиваться файлы, изменённые **с
`2026-10-01T00:00:01+03:00` включительно**, независимо от часового пояса компьютера.
Учитывается время последнего изменения файла на Диске. Чтобы отключить фильтр,
очистите поле даты и нажмите Enter.

Дата сохраняется как `MODIFIED_SINCE` в `.env` и применяется во всех режимах:
личные и Общие Диски, один источник или список CSV, меню и командная строка.
Без даты выгружаются все файлы. Обход папок сохраняется целиком, чтобы не пропустить
подходящие файлы внутри старых папок. Если при включённом фильтре сервер не вернул
корректное время изменения файла, файл пропускается с ошибкой; итог выгрузки
считается неуспешным.

Реквизиты сервисного приложения можно настроить отдельно:

```shell
uv run --locked python downloader.py --configure
```

Вместо меню можно создать `.env` по образцу `.env.example` с переменными
`CLIENT_ID`, `CLIENT_SECRET`, `MAX_RETRIES`, `DOWNLOAD_DIR` и `MODIFIED_SINCE` или задать их
в окружении процесса.
При загрузке настроек переменные окружения имеют приоритет над `.env`.

## Личные Диски

Один пользователь:

```shell
uv run --locked python downloader.py --email user@example.com
```

Список пользователей в `users.csv` — по образцу [users.example.csv](users.example.csv):

```csv
email
user1@example.com
user2@example.com
```

```shell
uv run --locked python downloader.py --csv users.csv
```

Файлы сохраняются в отдельную папку с email пользователя внутри выбранной папки
загрузки, например `<папка загрузки>/user@example.com/`.

## Общие Диски

Откройте Общий Диск в браузере и скопируйте его метку из фрагмента URL
`/vd/<VDHASH>/`. Указывайте только метку, без URL, сохраняя регистр символов.
`--email` задаёт сотрудника, которому разрешено чтение этого диска: токен
получается от его имени. VDHASH не заменяет email и сам по себе не предоставляет доступ.

Один диск:

```shell
uv run --locked python downloader.py --email reader@example.com --vdhash ExampleDiskHash1
```

Список в `shared-disks.csv` — по образцу [shared-disks.example.csv](shared-disks.example.csv):

```csv
VDHASH
ExampleDiskHash1
ExampleDiskHash2
```

```shell
uv run --locked python downloader.py --email reader@example.com --vdhash-csv shared-disks.csv
```

Для всего списка используется один email сотрудника с доступом к этим дискам.
Каждый диск сохраняется в `<папка загрузки>/shared/<VDHASH>/` с исходной структурой папок.
Если локальные имена совпадают без учёта регистра, к имени добавляется суффикс.

Оба вида CSV поддерживают UTF-8, в том числе с BOM, и разделители `,` или `;`.
Можно использовать нужную колонку в таблице с другими колонками либо список
без заголовка, по одному значению в строке. Пустые строки и повторы пропускаются.
Для email регистр не учитывается; для VDHASH — учитывается. Весь CSV проверяется
до начала выгрузки.


## Остановка и повторный запуск

Для остановки нажмите Ctrl+C один раз и дождитесь выхода: активные скачивания
отменяются, временные файлы удаляются, готовые файлы сохраняются.

Повторите ту же команду или выберите те же параметры в меню, сохранив прежнюю
папку загрузки. При относительном пути или настройке по умолчанию запускайте
загрузчик из той же папки.
Уже скачанные файлы проверяются по размеру и контрольной сумме SHA-256 или MD5,
если сервер её передал, и пропускаются без перезаписи. В статусе они отмечаются
как «уже скачано». Если сервер не передал ни размер, ни контрольную сумму,
существующий файл остаётся без изменений, а в журнале появляется ошибка проверки.

Неполные файлы или файлы, не совпадающие с текущей версией на Диске, скачиваются
заново с начала. Загрузка идёт во временный `.disk-download-*.part`; готовое имя
файл получает только после окончания скачивания и проверки. При ошибке старая
локальная копия сохраняется.

После принудительного завершения процесса могут остаться `.part`-файлы.
Повторный запуск их не использует и начинает незавершённые скачивания с нуля.
Оставшиеся `.disk-download-*.part` можно удалить, когда загрузчик остановлен.

Соответствие удалённых и локальных имён сохраняется в служебной папке
`.disk-downloader` рядом с папками пользователей, а для Общих Дисков — внутри
`shared`. Не удаляйте её при повторных запусках и переносите вместе с выгрузкой:
она сохраняет прежние пути при появлении новых файлов с похожими именами и при
изменении списка CSV. Одновременные выгрузки в одну папку блокируются; после
завершения процесса блокировка снимается автоматически.

При первом запуске новой версии прежние файлы с неоднозначными или изменёнными
при нормализации именами сохраняются отдельно: загрузчик может скачать их ещё
раз под новым именем. Это защищает старые копии, для которых ещё нет сохранённого
соответствия. Обычные имена продолжают использоваться без изменений.
Символические ссылки и Windows junction внутри папок выгрузки не обходятся.

Папки обходятся за один проход. Ошибка чтения одной ветки не мешает выгрузке
остальных; итоговый код остаётся `1`. Одновременно работают не более десяти
задач скачивания. Список обнаруженных файлов пока хранится в памяти, поэтому
объём потребляемой памяти зависит от числа файлов и папок.

## Статус и обновление токена

Токен обновляется автоматически за 5 минут до истечения часового срока,
в том числе во время долгого скачивания. 

Статус выводится каждые 30 секунд 
«Без новых результатов» означает время
с последнего обновления счётчиков; запрос к API или скачивание большого файла
могут продолжаться в это время. Интервал можно изменить:

```shell
uv run --locked python downloader.py --email reader@example.com --vdhash-csv shared-disks.csv --status-interval 5
```

В конце выводится итог. Код завершения: `0` — без ошибок,
`1` — есть ошибки выгрузки, `2` — ошибка входных данных, `130` — отмена через Ctrl+C.
Меню при выходе возвращает `1`, если хотя бы одна выгрузка в этой сессии завершилась с ошибками.
Для запуска без интерактивного терминала используйте параметры командной строки.

Справка:

```shell
uv run --locked python downloader.py --help
```
